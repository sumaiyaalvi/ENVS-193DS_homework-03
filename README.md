# ENVS-193DS_homework-03
Repository for homework 3

# General information

This repository contains Homework 3 for ENV S 193DS. The project analyzes ecological data (pickleweed and soil salinity), personal screen time data using statistical tests and data visualization, and a statistical critique of a research paper about the role of environmental gradients in non-native plant invasion into burnt areas of Yosemite National Park, California.

This repository belongs to Sumaiya Alvi and was completed individually for the course.

# Data and file information

The repository includes the following folders and files:

* `data/`: Contains the pickleweed and soil salinity dataset for Problem 1, as well as my personal screen time dataset.
* `code/` – Contains homework-03.qmd, the Quarto file with all analysis and visualizations, and the rendered HTML output.
* `.gitignore`, `.RData`, `.Rhistory`, and this `README.md`.

The code performs visualization, assumption checking, simple linear regression, correlation analysis, and displays my affective visualization.
